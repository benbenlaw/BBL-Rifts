Changelog BBL Rifts

# 1.2.0
- A lot of these changes are to make the mod feel more complete and feature rich more stuff will come 
- A full set of rift_protective_armor now provides creative flight inside the rift dimension, for rift armour the armor must be charged
- Added missing steel tags
- Added missing translations
- Creative rift energy now auto pushes rift energy 
- Added full wooden set for rift planks
- Added full stone block set for Rift stone including new Rift Stone Bricks
- Added Rift Surge Core When this block is fully powered it will explode causing a rift surge event. basically a raid of mobs which drop loot
- Furnace and Crushers now have tiers basic, advanced elite and ultimate with 1, 3, 6 and 10 slots for recipes
- Displacers are now generated for any dimension, still uses data maps but inside dimension folder now
- Added Rift Portal Gun, allows the placement of 2 portals that can be traveled through 
- Renamed a bunch of classes that were still referencing the old mod names
- Renamed some block and items 
- Updated guide me 

# 1.1.0
- Added Rift Converter, this can convert a block into a different one using rift energy and time
- Can have a to and from dimension to make it so the block starts as diamond in one and become emerald in the other and returns to the converter
- Uses BlockTarget and BlockStateResult (from In World Recipes), allowing for any resulting blockstates

# 1.0.2
- Some textures are still missing
- Changed the Rift Generator to use the new rift portal texture 
- Rifts will now try and spawn you on the world surface instead of creating a platform 
- Added JEI to the infuser
- Added Rift Leaves to the displacer 
- Added Rift Quarry, uses focuses to mine ores, recipes are wip and will change
- Changed to translations instead of literal in text 

# 1.0.1
- Rift Energy now only generates in the Rift dimension
- Can now summon rift portals
- Rift portals now only summon when where valid rift armor
- Updated guide me book with a lot more relevant information
- Crusher recipes now use SizedIngredient on output allowing for tag outputs
